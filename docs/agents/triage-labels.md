# Triage 标签

各技能以五个标准 triage 角色来描述 issue 状态。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义                                   |
| -------------------------- | ----------------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`          | 需要维护者评估此 issue                 |
| `needs-info`               | `needs-info`            | 等待提交者补充信息                     |
| `ready-for-agent`          | `ready-for-agent`       | 需求已完整明确，可交给无人值守的 agent |
| `ready-for-human`          | `ready-for-human`       | 需要人工实现                           |
| `wontfix`                  | `wontfix`               | 不予处理                               |

当技能提到某个角色（例如“打上 AFK-ready 的 triage 标签”）时，使用上表中对应的标签字符串。

如需改用其他命名，直接修改“本仓库 tracker 中的标签”一列即可。
